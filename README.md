# 松山大学 リンク集 (matsuyama-u-links)

松山大学の学生・教職員向けキャンパスサービスリンク集です。

## 概要

よく使うキャンパスシステム・サービスへのリンクをまとめたシンプルなレスポンシブ静的サイトです。

## 収録セクション

| セクション | 内容 |
|-----------|------|
| ⭐ よく使うサービス | Moodle, UNIPA, Gmail, Google Classroom |
| 🆘 困ったとき | ログインできない場合, Q&A, セキュリティ対策 |
| ✏️ 授業・課題 | Moodle, Google Classroom, シラバス検索, 教員情報検索 |
| 📬 メール・掲示板 | Gmail, UNIPA（PC版・スマホ版）|
| 💻 オンライン授業用ツール | Google Meet, Microsoft Teams, Zoom |
| 📶 学内無線LAN | キャンパス Wi-Fi 接続方法 |
| 📁 ファイル・動画共有 | Google Drive, YouTube（授業動画）|
| 📖 マニュアル・各種情報 | 公式HP, シラバス検索, 教員検索, OPAC, セキュリティ |
| 📣 お知らせ | 最新のお知らせ + 過去のお知らせ（折りたたみ）|

## 使用技術

- **HTML5** — セマンティックマークアップ
- **CSS3** — モバイルファーストレスポンシブデザイン（CSS Grid）
- **Vanilla JavaScript** — 過去のお知らせの開閉のみ

## ファイル構成

```
├── index.html   # メインページ
├── style.css    # スタイルシート
└── README.md    # このファイル
```

## レスポンシブグリッド

| 画面幅 | カラム数 |
|--------|---------|
| スマートフォン（< 600px） | 1列 |
| タブレット（600px〜） | 2列 |
| PC（900px〜） | 3列 |
| ワイド PC（1100px〜）※よく使うサービスのみ | 4列 |

## アカウント種別バッジ

各リンクには利用するアカウント種別をバッジで表示しています。

- 🔵 **松大アカウント** — @g.matsuyama-u.ac.jp の Google アカウント
- 🟢 **学籍番号** — 学籍番号・パスワードでログイン（Moodle, UNIPA など）
- 🟦 **Zoomアカウント** — Zoom 専用アカウント

## ローカルでの確認方法

```bash
# 任意の静的ファイルサーバーで開く例
npx serve .
# または
python3 -m http.server 8080
```

その後ブラウザで `http://localhost:8080` を開いてください。
