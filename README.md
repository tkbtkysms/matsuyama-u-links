# 松山大学 非公式リンク集 (matsuyama-u-links)

松山大学の学生・教職員向けキャンパスサービスリンク集です。

## 概要

よく使うキャンパスシステム・サービスへのリンクを1つの一覧にまとめた、シンプルなレスポンシブ静的サイトです。

## 主な機能

- **クリック数で自動並び替え**
  - 各リンクのクリック回数を `localStorage` に保存し、クリック数が多い順に表示します。
- **タグ絞り込み**
  - 各リンクにタグを付与し、タグボタンで絞り込みできます。
- **重複リンクの整理**
  - セクション分割を廃止し、同一リンクの重複掲載をなくしました。
- **Geminiリンクを追加**
  - Google Gemini へのリンクを追加しています。

## 使用技術

- **HTML5** — セマンティックマークアップ
- **CSS3** — モバイルファーストレスポンシブデザイン（CSS Grid）
- **Vanilla JavaScript** — リンク描画・タグ絞り込み・クリック数記録

## ファイル構成

```
├── index.html   # メインページ
├── style.css    # スタイルシート
├── script.js    # リンクデータとUIロジック
└── README.md    # このファイル
```

## レスポンシブグリッド

| 画面幅 | カラム数 |
|--------|---------|
| スマートフォン（< 600px） | 1列 |
| タブレット（600px〜） | 2列 |
| PC（900px〜） | 3列 |
| ワイド PC（1200px〜） | 4列 |

## ローカルでの確認方法

```bash
# 任意の静的ファイルサーバーで開く例
npx serve .
# または
python3 -m http.server 8080
```

その後ブラウザで `http://localhost:8080` を開いてください。
